## 🔧 Cómo Utilizar el Sitio

1. **Clonar el repositorio**
   ```bash
   git clone https://github.com/oficialmegamente4-creator/carlitos-tech-web.git
   cd carlitos-tech-web
   ```

2. **Abrir el archivo index.html**
   - Abrir `index.html` en un navegador web
   - O usar un servidor local (recomendado)

3. **Configurar servidor local (opcional)**
   ```bash
   # Usando Python 3
   python -m http.server 8000
   
   # Usando Node.js (http-server)
   npx http-server
   ```

4. **Acceder a través del navegador**
   - `http://localhost:8000` (Python)
   - `http://localhost:8080` (Node.js)
